# Cryo Divide — Legal

Публичные юридические страницы игры **Cryo Divide** (`com.goethe47.cryodivide`, Android).

Политика описывает LevelPlay/Unity Ads, возрастное отключение рекламного SDK, техническую диагностику Unity, локальные данные и отдельно добровольную будущую игровую аналитику. Страница лицензий перечисляет всё стороннее, что распространяется внутри игры.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Политика конфиденциальности (English) |
| `licenses.html` | Лицензии движка, SDK, шрифтов, звука и текстур (English) |
| `styles.css` | Оформление в палитре внутриигрового интерфейса |
| `fonts/` | Oswald и IBM Plex Sans Condensed (OFL 1.1) — те же шрифты, что в игре |
| `horizon.jpg` | Фон шапки: `Art/Background/FrozenHorizon_v2.png` из игры, ужат до 1400 px и 40 КБ |

Тема одна, светлая: игра сейчас светлая и ледяная, а страница повторяет её палитру — бумага `#e9eef2`, чернила `#1b252e`, единственный акцент `#ff5704` (оранжевый активной вкладки командного центра). Переключателя тем нет.

Шрифты лежат в репозитории и подключаются локально через `@font-face`. Это сделано намеренно: страница о приватности не должна отправлять IP читателя шрифтовому CDN.

## Публикация

Сайт статический и рассчитан на GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `root`**. Файл `.nojekyll` отключает обработку Jekyll.

Адрес:

```text
https://goethe47.github.io/Cryo-Divide-Legal/
```

## Обновление

При изменении текста политики нужно поправить дату в двух местах `index.html`: в блоке `.meta` и в подвале. То же самое для `licenses.html`.

Источник данных для страницы лицензий — файлы проекта игры: `THIRD_PARTY_NOTICES.md`, `Assets/CryoDividePrototype/Audio/AUDIO_LICENSES.md`, `Assets/CryoDividePrototype/Art/Fonts/FONT_LICENSES.md` и `Packages/manifest.json`. При добавлении нового стороннего ассета правится сначала проект, потом эта страница.
