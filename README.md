# Cryo Divide — Legal

Публичная страница юридических документов игры **Cryo Divide** (`com.cryo.divide`, Android).

Сейчас здесь опубликована политика конфиденциальности на русском и английском языках — ссылка на неё указывается в Google Play Console.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Политика конфиденциальности (RU/EN, тёмная и светлая темы) |
| `styles.css` | Оформление в палитре внутриигрового интерфейса |

Язык и тема определяются по настройкам системы и запоминаются в `localStorage`.

## Публикация

Сайт статический и рассчитан на GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `root`**. Файл `.nojekyll` отключает обработку Jekyll.

Адрес после включения Pages:

```text
https://goethe47.github.io/Cryo-Divide-Legal/
```

## Обновление политики

При изменении текста нужно поправить дату в трёх местах `index.html`: в блоке `.meta` русской и английской версий и в подвале обеих версий.
